# Порядок реализации фичи

Когда просят собрать фичу, выдавай полный стек строго в этом порядке:

1. Migration & Model
2. Repository
3. Service/Action
4. Controller
5. Form Request & Resource
6. Vue Component (with i18n & Dark Mode)

Архитектурные ограничения по каждому слою (тонкие контроллеры, запросы только в репозиториях,
исключения вместо `true/false`, обязательные Resource и Form Request) заданы в `CLAUDE.md`
и действуют всегда — этот навык задаёт только последовательность.
